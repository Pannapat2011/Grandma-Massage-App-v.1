โหมดพื้นฐาน (ฟรี): อ่าน QR บนสลิป ตรวจว่าเป็นรูปแบบสลิปธนาคารจริง และ กันสลิปซ้ำ (สลิปเก่าใช้ซ้ำไม่ได้ตลอดไป) — แต่ยอดเงินพนักงานต้องดูเองบนสลิป

โหมดตรวจกับธนาคาร (SlipOK): ระบบถามธนาคารให้ว่าโอนจริงไหม ยอดเท่าไหร่ เข้าบัญชีร้านหรือเปล่า — กันสลิปปลอมได้ด้วย สมัครที่ slipok.com แล้วนำ Branch ID กับ API Key มาใส่

ตรวจจับเงินเข้าอัตโนมัติ (Android)

ให้มือถือที่ติดแอปธนาคาร ส่งข้อความแจ้งเตือน “เงินเข้า” มาที่ระบบผ่านแอปฟรี MacroDroid — ถ้ายอดตรงกับที่กำลังโชว์ QR อยู่ ระบบจะกดยืนยันรับเงินให้เอง

  1. ติดตั้ง MacroDroid จาก Play Store บนมือถือที่มีแอปธนาคาร และเปิดแจ้งเตือนเงินเข้าในแอปธนาคาร
  2. กด เพิ่มมาโคร → ทริกเกอร์: การแจ้งเตือน › ได้รับการแจ้งเตือน → เลือกแอปธนาคาร (เช่น K PLUS, SCB EASY, กรุงไทย NEXT) → ข้อความมีคำว่า เงินเข้า (หรือ “รับเงิน”)
  3. แอคชัน: เว็บ/HTTP › HTTP Request → วิธี POST → ใส่ลิงก์ด้านบน → Body เลือกแบบข้อความ (text/plain) แล้วกดปุ่มเติมข้อความพิเศษ ใส่ ชื่อเรื่องการแจ้งเตือน + ข้อความแจ้งเตือน
  4. ตั้งค่ามือถือ: ให้ MacroDroid ใช้แบตไม่จำกัด และล็อกแอปไว้ในหน้าแอปล่าสุด (vivo/iQOO ปิดแอปพื้นหลังบ่อย)
  5. กด “ทดสอบเงินเข้า” ด้านล่าง หรือให้เพื่อนโอน 1 บาทมาลองจริง
